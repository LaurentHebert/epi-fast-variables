# Fast-variable reduction to complex contagion unifies epidemic models

Python files to reproduce main figures from "Fast-variable reduction to complex contagion unifies epidemic models" by Hébert-Dufresne, Simon & Kiss.

### Codes

The file fast_variable_figure.py contains all model elements and other files draw from it.

Requires: numpy, scipy, matplotlib.   Run:  python fast_variable_figure.py
